# Additional doodle scenes

Generated with the built-in image-generation tool, using `frontend/public/illustrations/voice-studio-doodle-v2.png` as a style reference. Output PNGs preserve transparency and are saved in `frontend/public/illustrations/`.

These scenes support the interactive homepage use cases, the closing call to action, transcript/history screens, and the API-key empty state. Fonts remain Ubuntu/Kantumruy Pro and backgrounds remain plain.

## Shared prompt

Use case: illustration-story. Create a NEW companion HAND-DRAWN DOODLE for the same website as the reference. Reference image is STYLE GUIDANCE only. Match the charming irregular black fineliner outlines, black scribbled hair, very simple dot eyes and tiny smiles, warm off-white paper fills, saffron-orange scribbled accents and small loose hatch marks. MUST be playful ink doodle, NOT realistic, painterly, shaded, 3D, or vector primitives. Genuinely transparent background. Landscape 4:3, isolated centered composition filling 85% of frame with comfortable margins, all objects fully visible. Black ink, warm off-white, saffron orange ONLY. Simple believable anatomy and clear silhouettes, no tangled arms, no full-body legs. No background pattern, no enclosing arch or blob, no words, lettering, logos or watermarks. Reads clearly at 400px wide.
